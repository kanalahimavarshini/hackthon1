# CarbonIQ — Carbon Footprint Intelligence Platform

A responsive climate-tech hackathon website prototype.

## Features

- Environmental performance dashboard
- Equipment monitoring interface
- Video upload and preview
- Digital Twin scenario simulator
- Carbon emissions calculator
- Demo sustainability assistant
- CSV report export
- Print and save report as PDF

## Technologies

- HTML
- CSS
- JavaScript

## Run on Windows

1. Create a folder named `carboniq-website`.
2. Save index.html, styles.css, app.js and README.md inside it.
3. Open the folder in Visual Studio Code.
4. Open index.html in your browser.

Alternatively, install the Live Server extension in VS Code.
Right-click index.html and select "Open with Live Server".

Node.js and npm are not required for this version.

## Important limitations

This project uses illustrative demo data.

The video upload feature previews a video but does not perform
computer vision detection.

The AI assistant uses predefined example responses rather than
a live language model.

The Digital Twin is an interactive estimate, not a connection
to real equipment.

Real deployments require verified energy data, appropriate
emission factors, and backend integration for computer vision
and generative AI.
